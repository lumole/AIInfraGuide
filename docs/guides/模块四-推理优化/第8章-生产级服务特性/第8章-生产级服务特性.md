模型能返回文本，不等于服务能稳定承接应用。本章把六类生产能力拆开：约束输出、工具调用、Adapter、多模态、采样语义和端到端验收。每一节先给可跟读教程，再说明哪些行为必须按当前模型与 vLLM 版本核对。

## 本章小节

- **8.1 结构化输出**：JSON Schema/grammar 怎样转成 token mask，以及如何验证回退。
- **8.2 Tool Calling 与 Reasoning Parser**：模型模板、工具 schema、解析器与错误边界。
- **8.3 Multi-LoRA 服务**：共享 base model、动态 Adapter 与批内混合。
- **8.4 多模态推理**：processor、占位 token、图像预算与缓存。
- **8.5 采样与解码算法**：从 greedy 到 top-p，明确 API 参数的组合语义。
- **8.6 生产验收**：流式、取消、错误、观测、隔离和灰度的一体化门禁。
