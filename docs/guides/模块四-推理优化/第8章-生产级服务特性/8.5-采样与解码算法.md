## 主教程

[Hugging Face：Generation Strategies](https://huggingface.co/docs/transformers/main/en/generation_strategies) 从 greedy、sampling 到 beam search 按策略给出解释和代码。先用小模型运行示例，再核对服务端参数。

## 一步采样的顺序

不同实现的 processor 顺序可能不同，因此“temperature=0.7、top_p=0.9”不能脱离版本比较。一个常见抽象流程是：

~~~mermaid
flowchart LR
    L["原始 logits"] --> P["penalties / allowed tokens"]
    P --> T["temperature"]
    T --> K["top-k / top-p / min-p"]
    K --> N["归一化概率"]
    N --> S["按 seed 随机采样"]
    S --> STOP["EOS / stop 条件"]
~~~

Greedy 每步取最大值，适合确定性基线；sampling 用温度和截断分布控制多样性；beam search 保留多个候选路径，成本与语义不同，不应当作普通 batch。

## 组合参数的验证

- temperature 接近 0 时是否转为 greedy，还是仍走采样；
- top-k、top-p、min-p 同时设置时按什么顺序；
- repetition/presence/frequency penalty 的定义和作用范围；
- seed 在连续批处理、并行度变化后是否保持可复现；
- stop token 与 stop string 是否包含在输出中；
- logprob 是处理前还是处理后的分布；
- 结构化输出和工具调用如何叠加 logits mask。
