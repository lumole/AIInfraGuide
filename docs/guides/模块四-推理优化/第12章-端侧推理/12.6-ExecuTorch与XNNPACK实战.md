## 跟读顺序

1. [ExecuTorch：How It Works](https://docs.pytorch.org/executorch/stable/intro-how-it-works.html)：先看 export、compile、runtime 的全流程图。
2. [XNNPACK Backend Tutorial](https://docs.pytorch.org/executorch/stable/tutorial-xnnpack-delegate-lowering.html)：跟随当前版本代码完成 export、partition、serialize 和运行。
3. [ExecuTorch XNNPACK Backend](https://docs.pytorch.org/executorch/stable/backends-xnnpack.html)：遇到算子和配置问题时查能力范围。

官方教程已经给出完整可运行步骤，本页不复制容易过时的 API。实际练习应固定 PyTorch/ExecuTorch commit，并保存生成产物。

## 实验应回答什么

### 导出

- 输入 shape 约束是什么；
- 是否存在 graph break 或 unsupported Python；
- eager 与 exported program 的输出误差是多少。

### Partition

- 哪些节点被 XNNPACK 接管；
- 哪些节点留在 portable CPU；
- delegate 边界是否插入布局/类型转换；
- fallback 是否符合预期。

### 运行

- 模型加载、首轮和稳态延迟；
- 线程数对延迟与功耗的影响；
- 峰值内存与产物大小；
- 多次运行是否有泄漏或结果漂移。
