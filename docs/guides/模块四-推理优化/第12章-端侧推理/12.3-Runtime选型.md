## 主教程

[ML Runtimes Primer](https://aman.ai/primers/ai/ml-runtimes/) 提供统一框架比较多种 runtime，适合先读。选定候选后再进入各家官方文档核对平台与 backend。

## 不按品牌名选 Runtime

先列功能硬约束：来源框架、目标 OS/SoC、CPU/GPU/NPU、模型格式、动态 shape、自定义算子、量化、包体、线程、内存、调试工具和许可证。任何关键项不支持，就不进入性能比较。

## 三类候选

| Runtime | 常见优势 | 重点核对 |
| --- | --- | --- |
| ExecuTorch | PyTorch 原生导出与 backend delegate | PyTorch/模型兼容、目标 backend |
| ONNX Runtime Mobile | ONNX 生态与多 Execution Provider | 算子覆盖、EP partition、ORT format |
| LiteRT | Android/Google 端侧生态和 delegate | 转换链、delegate、平台版本 |

这张表只用于缩小候选，不能代替目标设备实测。

## 同模型比较协议

1. 使用同一权重、相同量化目标和输入样例。
2. 分别记录导出成功率、unsupported op 和 fallback。
3. 在同一设备测冷启动、热启动、稳态延迟、峰值内存、包体和功耗。
4. 比较结果数值与任务质量。
5. 记录集成、日志、profiling、升级和回滚成本。
